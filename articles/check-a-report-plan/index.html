Check a Report Plan in Decision Lab

Run a three-day report plan, inspect the pending independence check, and see what changes when the deadline moves.

Can a report be prepared and independently reviewed by the end of day three? This guide turns that question into a small description you can run in the Free Decision Lab public beta. You will inspect a feasible schedule, distinguish it from an unconfirmed requirement, and change one constraint to see the effect.

The facts are fictional: Noah is available on days one and two, preparation takes two days, Maya is available on day three, and review takes one day. Review must start after preparation finishes. The meaning and evidence required for reviewer independence still need human examination.

1. Enter the plan

Open Decision Lab and select the free beta action. In Workspaces, select New workspace if the start choices are hidden, then Blank description. Under Author, select Description; a new blank workspace initially shows Definitions.

Paste the complete source below into Your description. This example uses the built-in planning phrases, so it needs no additional definition file. Use ordinary straight double quotes and keep the final Find arrangements instruction.

You can also open the report-plan.hermod source file, save it, and select Open file in Workspaces to import it as a separate workspace.

The first statements name the objective, steps, resources, and check. The remaining statements connect them and supply the calendar, availability, duration, order, and deadline. You authored each of these premises; the analysis evaluates them together.

2. Analyze and read the schedule

Select Analyze. When the workspace status reads Analysis current, open Results, then Reports, then Arrangements. Expand Timing and resource report. If only the code pane is visible, select Both or Results in the workspace controls.

For this source, the analysis returns one arrangement with a feasible schedule:

Expected schedule from the complete report plan
WorkPersonPlanned days
Prepare reportNoah1–2
Independent reviewMaya3

The result fits the declared availability and timing. Review follows preparation, and the plan finishes by day three. The two named assignments are fixed in this model; it searches for a feasible arrangement under those assignments, rather than choosing from a list of possible reviewers.

3. Inspect what remains unresolved

In Arrangements, Confirm reviewer independence appears under Required contributions and checks. Expand Evidence readiness for this arrangement to inspect its unresolved evidence. In the timing report, the same check is listed under Required work without planned dates.

Why is it there? The description explicitly says that Independent review requires this check. Calling the step “Independent review” and assigning it to Maya do not establish the applicable criteria or supply evidence that she meets them.

Ask the responsible person what independence requires for this report. Does it mean someone other than the preparer, or does it also exclude someone who advised on the work? Seek the relevant facts before recording a conclusion. These are manual clarification prompts for you; this example contains no recorded answer or evidence assessment.

A useful answer may leave the schedule unchanged while exposing an unsupported assumption. The check remains pending in this supplied model. If clarification changes the work or assignments, revise the relevant description and analyze it again.

This result concerns this description. A different reviewer, a different duration supported by the work, or a revised deadline would be a change to the problem. Restore the day-three deadline and analyze again to recover the original feasible schedule.

5. Keep the description and result

Select Export → Complete description (.hermod) for an editable copy. Analysis results (.json) and Report (.md) preserve calculated output in structured and readable forms. Use Workspaces → Open file to reopen the complete description as a separate workspace and run it again.

Workspaces are saved in this browser. Keep an exported file when you need an independent copy. A feasible schedule describes planned timing; completed work, supporting evidence, and permission to proceed require their own records and judgments.
