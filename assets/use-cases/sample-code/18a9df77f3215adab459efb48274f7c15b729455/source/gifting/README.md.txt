# Gifting integrations

These examples form one continuing team process:

- [Gift-kit Preflight](gift-kit-preflight/README.md) uses the public CLI to screen independent campaigns and export a portable native review with owners, source receipts and the next action.
- [Gift-kit Handoff Desk](gift-kit-handoff-desk/README.md) uses the public SDK and ordinary React hooks to resolve one of those exact reviews, record an operating decision and retain actual correction/rehearsal/handoff records.

A new cost-first version 3 profile makes the tradeoff concrete: cheap in-house correction when time permits, a premium external package when it alone protects the cutoff, and less work only when actual scoped diagnostic evidence supports it. Existing version 2 marketplace releases remain immutable.

The apps share native workflow history, source/assessment identity checks and operating-record integration code. Domain rules come from portable configuration, and reports use the reusable views. Neither client performs production, authenticates external approvals or guarantees a shared resource across campaigns.
