What Is a Question Worth?

Entropy, experiment cost, and the value of information, explained with marbles and Decision Lab.

Someone hands you a bag of 1,024 marbles. Exactly one is heavier than the others. You have a balance and a question: which marble is it?

You could check them individually. You could divide them into groups. Both approaches can eventually answer the question, but they require very different amounts of work.

Next, keep the same 1,024 marbles and put 512 in a red bag and 512 in a blue bag. There is still exactly one heavy marble across both bags. Change the question: which bag contains it? We now need less detail, even though the physical uncertainty about the marble remains.

Then introduce a separate game in which bags have different payouts and you can buy a test before choosing one to redeem. That adds a reason to care about the answer. Finally, give the choice a deadline: useful evidence must arrive with time left to act.

These steps change different parts of the problem: the search strategy, the required answer, the consequences of choosing, and the conditions for acting. We will build each idea from first principles, then work through a live example in Decision Lab.

What changed about the decision?

Trying a different search strategy keeps the identification question fixed. Asking for the containing bag changes the required distinction. Adding payouts changes how choices are valued. Adding a deadline limits the plans that can support the commitment.

The panels below keep those changes separate. The first two use the same 1,024 marbles and the same single heavy marble. The payout game and app demonstration each announce their own physical rules.

Ask what counts as enough in this version. A result can be insufficient for exact identification, sufficient for identifying a bag, and economically irrelevant to a particular choice.

One shared structure, different conditions

An ontology names the kinds of things in a problem and their relationships. Here it must connect bags and marbles to possible explanations, experiments, required answers, actions, consequences, and execution conditions. These are the concept families we will reuse across the cases.

The same structure can hold different facts and rules. The heavy-marble allocation rule is particularly important:

In the payout game, the final question is which bag to redeem; the proposed test asks which blue payout tier is heavy. The evidence question serves the choice. Changing a count, deadline, or required answer changes the case’s inputs or requirements while these concept families can remain the same.

Begin with the possibilities

Before weighing anything, there are 1,024 possible answers. The heavy marble could be marble 1, marble 2, and so on. Suppose each is equally likely. These are hypotheses about the same physical situation, rather than 1,024 different physical experiments.

An observation is useful when it distinguishes among those possibilities. If a result rules out half the candidates, we have less uncertainty than before. If it leaves every possibility equally plausible, it has not answered this particular question.

For now, make the apparatus ideal: the balance is reliable, the unusual marble is known to be heavier, and normal reference weights are available when needed. We will keep monetary cost and handling time out of the puzzle until we have understood the information.

Three ways to ask the question

Check one marble at a time. Compare each candidate with a normal reference. If the first 1,023 are normal, the last must be heavy. The worst case takes 1,023 weighings.

Ask which half contains it. Divide the candidates into halves and use a comparison that identifies the half containing the heavy marble. Repeat with that half. Since 210=1,024, ten successive halvings suffice to identify any marble.

Use all three balance outcomes. Put 341 marbles on each pan and leave 342 aside. If the left side is heavier, keep that group. If the right is heavier, keep the other. If they balance, keep the group that was never on the scale. Continue with roughly equal groups.

The individual-checking line rises almost one-for-one with the number of marbles. Halving adds just one weighing whenever the candidate count doubles; three-way splitting adds one whenever it triples. At 1,024 marbles, the contrast is 1,023 weighings versus 10 or 7. The advantage is in how slowly the work grows as the search gets larger.

Worst-case weighing counts

The three-way advantage comes from three distinguishable results, each of which selects a useful continuation. Merely making three piles is not enough. This comparison counts weighings; we will add handling time and other experiment costs below.

All three strategies still aim to identify the exact marble under the same physical premises. We have changed how we investigate, while keeping the required answer fixed.

Entropy: how much uncertainty remains?

Imagine asking perfectly chosen yes-or-no questions. One answer can distinguish two equally likely possibilities. Two answers can distinguish four. Three can distinguish eight. Each additional answer doubles the number of possibilities we can distinguish.

This suggests a logarithmic measure. For N equally likely possibilities, the uncertainty is

H=log2Nbits.

For our 1,024 equally likely marbles, the entropy is exactly 10 bits. Ten evenly divided binary questions can resolve it completely. Entropy is an average-information quantity, so it need not match a whole-number worst-case question budget in other problems.

More generally, if hypothesis i has probability pi, Shannon entropy is

H(X)=−∑ipilog2pi.

The probabilities matter. A bag with one overwhelmingly likely candidate has less uncertainty than a bag with the same number of equally likely candidates. The logarithm’s base determines the unit: base two gives bits. Entropy provides a lower bound on the average number of binary answers needed for exact identification under an appropriate question scheme.[1], [2]

A bit is an amount of information, not a dollar or a minute. For equally likely candidates, halving the remaining possibilities removes one bit of uncertainty.

That distinction helps us avoid a common mistake. Ten binary weighings and seven three-outcome weighings solve the same initial identification problem. They use different information channels, rather than starting with different amounts of uncertainty.

Information gain: what does an experiment teach us?

Suppose the first half-versus-half comparison identifies a group of 512. The uncertainty has fallen from log21024 to log2512. The reduction is exactly one bit:

log21024−log2512=1.

By contrast, an individual check usually says only that one marble is normal. It eliminates one candidate out of 1,024. The rare result that identifies the heavy marble is extremely informative, but most results teach very little.

A test with three equally likely, fully distinguishing outcomes can provide log23≈1.585 bits. Our first three-way split is almost equally balanced, so its expected gain is very close to that maximum.

Before running a test, we do not know its result. We therefore compare experiments by their expected information gain: initial uncertainty minus the average uncertainty remaining after the possible results. If X is the unknown heavy-marble location and Y is the test result, then

EIG=H(X)−∑yP(y)H(X|Y=y).

This is the mutual information between the location and the observation. The averaging matters: with unequal prior probabilities, a particular surprising result can increase posterior entropy even though expected information gain is nonnegative.[2]

For an informative search, divide the probability mass into useful result groups. Equal group sizes achieve that in our uniform example. When candidates have unequal probabilities, the best probability split need not have equal numbers of marbles.

Experiment cost: what must we spend to learn?

Now charge two credits per weighing. Ignoring handling and other work, the worst-case direct costs become 2,046 credits for individual checking, 20 for halving, and 14 for three-way splitting.

That is a cost model we have added to the experiment. It was not contained in the entropy calculation. If sorting large groups is slow, the strategy with fewer weighings might still consume more labor. Equipment, access, recording, interpretation, and the time needed to act can all matter.

A more complete learning plan therefore asks:

  • What distinguishes the possible explanations?
  • What resources does each test consume?
  • When will its result be interpreted and usable?
  • What choice could change after each result?

Information gain per credit can help compare ways to learn about a given question. It does not tell us whether answering that question is worth paying for. To understand that, we need a decision and its consequences.

Keep the marbles; change the required answer

Before adding prizes, change just the required distinction. Take the original 1,024 marbles, put 512 in a red bag and 512 in a blue bag, and retain the rule that exactly one marble across both bags is heavy. Suppose our task is now to identify its containing bag.

Put red’s 512 marbles on one pan and blue’s 512 on the other. Under the reliable, known-heavier premise, the heavier side identifies the bag. Equal pans are impossible in this comparison: exactly one side contains the heavy marble.

Call the marble identity M and its bag B. Before testing, the equally likely identities give

H(M)10 bits=H(B)1 bit+H(M|B)9 bits.

After the comparison, bag uncertainty is zero and marble uncertainty is nine bits. We have answered the bag question completely while leaving most of the original marble question unresolved.

Sufficient evidence depends on the question. One observation can settle bag identity while leaving exact marble identity open. No payout model has been added yet, so this establishes the required resolution, rather than a dollar value for the information.

Colored bags: give the information something to change

Start a new payout game. Red now contains nine marbles and blue contains 1,024. Each bag has one heavy marble, so there are two heavy marbles in total. This replaces the preceding rule of one heavy marble across both bags.

Every marble has a visible payout label. You may redeem one whole bag, and its heavy marble’s label determines your payout. The cashier checks the chosen bag after you commit, at no additional cost. You need not identify its exact marble yourself.

Red’s nine labels all say $60. Blue has 512 labels saying $100 and 512 saying $0, with every blue marble equally likely to be heavy. Use expected dollars as the scoring rule; all amounts are hypothetical.

Without a test, blue has expected payout

0.5($100)+0.5($0)=$50.

Red pays $60, so the best current choice is red.

Now you may buy a weighing for $5. Put blue’s 512 marbles labeled $100 on one pan and its 512 marbles labeled $0 on the other. The heavier side reveals which payout blue would produce.

The expected payout when we can use the result is

0.5($100)+0.5($60)=$80.

Compare that with the best choice available without the test:

Gross value of information=$80−$60=$20.

After paying $5, the expected payout is $75. The expected improvement over choosing red immediately is therefore $15.

This is the decision-theoretic meaning of value of information: the expected improvement from being able to choose after receiving evidence. Study cost is then deducted to obtain the net benefit of obtaining that evidence. The comparison must use the best available action in each case, rather than the prize amount alone.[3]

Before paying for an experiment, specify what you would do after each possible result. The value comes from the better decisions those results enable.

If the fee rises to $25, this test is no longer worthwhile under the scoring rule. If red instead guarantees $120, information about blue has zero value for choosing a bag: red wins in either state.

Two questions, one bit each, different value

The weighing above removes half the blue candidates. It gives one bit. Yet 512 marbles remain possible, and we already know which bag to choose.

Consider a different weighing. Divide blue into two mixed halves, each containing 256 marbles labeled $100 and 256 labeled $0. Weigh those halves against each other.

Whichever side is heavier, 512 candidates remain. We again gain one bit. But the remaining candidates are still half $100 and half $0. Blue’s expected payout remains $50. Red remains the best choice, and the test has zero gross decision value.

There is no universal dollars-per-bit conversion. The same amount of information can have different value because it changes different decisions. Once the useful weighing has settled this choice, identifying the exact marble supplies nine more bits but no further payout benefit under these rules.

How information reaches a decision

The shared ontology links the objects and rules. For the payout game, we can also draw a decision network: a view that separates unknown quantities, choices, and value. The result depends on both the chosen test and the hidden heavy-marble positions. The bag choice can use the test and its result. The payout depends on the chosen bag and the actual situation, while testing contributes cost.[4]

The important link is from the result to a subsequent choice. If the same action remains best after every possible result, the information has zero gross value for that decision. Its acquisition can still cost money.[5], [3]

A deadline adds an execution condition: the test must finish, the result must be interpreted, and the choice must be completed while it is still available. A result arriving after a fixed handoff cannot change that completed commitment. The deadline limits which evidence can be used; the payoffs establish why changing the choice matters.

Reset the physical rules again: there are nine marbles in total, arranged in three bags of three, with exactly one heavy marble across all three bags. Each bag is available at minute 0. The goal is to identify the containing bag and complete the choice before a handoff deadline.[7]

BAG-REPEAT repeats the bag comparison three times and uses its majority. Under the stated one-error bound, that establishes which bag contains the heavy marble. It does not need to identify which of that bag’s three marbles is heavy.

MARBLE-EXACT repeats each comparison three times and continues to the exact marble. It gathers additional detail, costs more, and misses the current deadline. This is the supplied strategy, rather than a claim that every exact-identification strategy must take six physical weighings.

An insufficient result is not necessarily a wrong result. It means the observations do not establish the required distinction under the allowed possibilities. A report can happen to be correct while still leaving an alternative explanation consistent with the model.

2+1prepare and sort+3(1+1)weigh and record+1interpret+1choose=11minutes.

The third observation is recorded at minute 9. Interpretation finishes at minute 10. The final choice finishes at minute 11. Against a minute-12 deadline, that leaves one minute of slack.

Learning within a case, or changing the case?

A new weighing result changes which explanations remain plausible and may change the next action. The bag counts, heavy-marble rule, and required answer can remain fixed. That is learning within the stated case.

Changing the required answer, replacing the allocation rule, allowing an incorrect report, or moving the deadline changes the case specification. Retain that revision alongside the observations so that an earlier finding can be read under the premises that supported it. The shared concept families can remain the same across both kinds of update.

Carry the decision structure into real work

Replace the bag with a supplier, a launch route, or a proposed process change. Replace a weighing with an audit, rehearsal, or bounded pilot. The useful questions remain recognizable:

  • Which alternatives are currently plausible, and how uncertain are we?
  • What could each observation distinguish?
  • What complete work is needed to obtain, interpret, and use it?
  • Which action would change after each result?
  • Does the expected improvement justify the cost and delay?

The mapping still needs scrutiny. Real tests can be noisy, explanations can overlap, and results can arrive too late or apply to a different situation. A model should retain those limitations alongside the judgment it supports.

Before carrying out a trial, write down the decision, the expected observations, and the response to each result. Afterward, retain what actually happened and revise the assumptions or proposed action. This connects the information calculation to an explicit learning cycle: plan, do, study, and act.[6]

In the payout game, one bit improves the expected decision by $20 while another bit changes nothing. In the app, one plan provides enough reliable distinction in time, while a more detailed plan misses the commitment. Both examples make the same demand of a learning plan: identify the decision it will support and show how its results can still change what happens next.

Before commissioning the next test, finish this sentence:

If we observe ________, we will choose ________; otherwise, we will ________. We need the result by ________, and obtaining it will cost ________.
