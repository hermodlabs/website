The debugging problem

Wireless failures leave evidence across several layers.

A device log may show that a report was created. A packet capture may show transmission. A gateway may have only part of the record. The application may only record a timeout.

Hermod organizes these records around the same event so teams can see where the evidence ends and which causes still need to be tested.

Missing

Determine whether the packet was created, transmitted, received, or dropped later.

Delayed

Trace where latency entered the event path.

Disconnected

Reconstruct the connection sequence around the failure.

Contradictory

Compare the sniffer, gateway, host, and application records for the same event.

What we’re building

A tool for cross-layer wireless debugging.

Hermod is designed to turn scattered technical records into a structured investigation. It helps engineers trace an event, evaluate possible causes, and decide what to measure next.

01

Align

Trace one event across the available records.

Line up device logs, packet captures, RF observations, gateway records, host events, timestamps, and sequence numbers around the same event.

02

Assess

Show what each record supports.

Mark verified steps, identify evidence gaps, and keep track of the causes that remain possible.

03

Next step

Recommend the next measurement.

Suggest the check most likely to narrow the cause or confirm where the failure occurred.
