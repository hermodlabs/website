01 / What you do in the beta

Write. Analyze.
Inspect and revise.

Start with a small question: can a report be prepared and reviewed by day three? The walkthrough supplies a complete description you can run and change yourself.

01

Write the description.

Open a blank description or an existing file in Workspaces, then select Author → Description. Enter named work, resources, requirements, and explicit connections using the supported phrases. You decide which facts and rules belong in the model.

Manual entry · visible source

02

Analyze and inspect.

Select Analyze to evaluate the supplied description. Inspect returned arrangements, their required checks, and the timing report. A schedule can fit while a required check remains pending.

Calculated fit · unresolved checks

03

Revise and keep a copy.

Clarify assumptions with the people involved, edit the description, and analyze again. Use Export to keep a complete description you can reopen, alongside the analysis results or readable planning report.

Human judgment · portable files

02 / Reading a result

The timing fits.
One check remains.

In the report example, the analysis returns one feasible schedule: Noah prepares on days one and two, and Maya reviews on day three.

The description also requires “Confirm reviewer independence.” That check remains pending. Assigning different people and finding time for their work does not confirm all the independence criteria that may apply.

You establish those criteria, seek the relevant evidence, and decide what to record. This walkthrough uses manual clarification; the questions in its explanation are prompts for the person using the model.

Results depend on the facts and rules supplied. A feasible arrangement establishes neither completed work nor permission to proceed.
